---
title: "Quantura MCP"
description: "Documentation and verified market discovery for MCP clients."
---

Connect to `https://quantura.mintlifysite.com/mcp`.
Alternate host: `https://quantura.mintlify.app/mcp`.

```json
{"mcpServers":{"quantura":{"type":"http","url":"https://quantura.mintlifysite.com/mcp"}}}
```

Mintlify supplies documentation search. Quantura's OpenAPI allowlists these
read-only API tools:

- `quantura_search_markets`
- `quantura_resolve_market_link`
- `quantura_browse_event_markets`
- `quantura_get_search_capabilities`
- `quantura_get_my_access`
- `quantura_list_workspaces`

API tools require [Mintlify's Pro/Enterprise API-tool feature](https://mintlify.com/docs/ai/model-context-protocol) and a refreshed
deployment. Check your client's tool list: if only documentation tools appear,
use the HTTP API directly. The allowlist does not guarantee live availability.

Market discovery is public and rate-limited. Account tools require a Quantura
API key in the client's secret facility and enforce current scopes/membership.
Never put keys in the MCP URL or checked-in configuration.

Uploaded CSV operations are excluded from discovery; their endpoints remain
compatible. No trading, mutation or expensive forecast job is enabled as an MCP tool.
