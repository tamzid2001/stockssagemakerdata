      How to read this screener

      Compare the latest completed daily input close with the first forecast quantile values. Quantiles describe a forecast distribution, not a recommendation or guaranteed outcome.

      Daily five-model ensemble

      Stock comparisons use the published daily close for an exchange session (normally 4 pm New York time; earlier on early-close days). After-hours movement does not change that historical close.

      Freshness and gaps

      Input date and forecast dates are explicit. Daily prices are split-adjusted. The prior validated dataset stays available while a new scan runs.
