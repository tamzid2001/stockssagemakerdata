# Quantura v2.2.0

## Accounts and API access

- Clerk is the primary web authentication provider, with Google and email/password, account and billing management. Verified administrator email and migrated user ID retain admin access. Legacy account/developer cards, orders and Team settings sections, workspace selectors, navigation sign-out links and session badges are removed; header search stays available in Profile.
- Node and retained Python APIs verify Clerk signatures, issuer, audience context and session claims. Migrated user IDs remain linked to existing private data.
- Firestore and Storage remain the data layer. A verified Clerk session can obtain a compatibility credential for their existing browser SDKs.
- Pro offers $199.99/month and $1,999.92/year in Clerk, both with a 14-day trial. Pricing requires sign-in before checkout; annual and monthly CTAs use the same Clerk billing flow.
- API keys and OpenAPI documentation require an active server-owned enterprise grant. Pro and its 14-day trial cover website features rather than programmatic access.

## Data and forecasts

- Public stock search and downloads use Alpaca without a Yahoo fallback.
- Gemini exchange discovery includes crypto and prediction contracts. Crypto forecasts use genuine completed candles; unavailable prediction history is reported explicitly.
- World Bank Data360 and Treasury Fiscal Data support discovery, dimension selection, historical previews, CSV downloads and forecasts at native frequencies.
- Uploaded CSVs have a browser-side preview and an editable series name before forecast submission. Signed-in users can save a CSV to private account storage and reopen its preview from Requests. Download settings are retained in Requests after a successful preview.
- Request history uses Forecasts, Downloads, Uploaded CSVs and Jev categories. Legacy Model Council responses display as Jev; retired Indicator requests are excluded.
- Kalshi perpetual screeners use completed daily observations and seven forecast days, with P01/P25/P50/P75/P90/P99 and available licensed ensemble participants.

## Website and operations

- All 78 blog articles have Previous blog, Next blog and Copy shareable link controls; each retains a distinct Unsplash image.
- Research copy is shorter, the About page includes a founder letter, and homepage stock cards include company logos.
- Pinterest verification is included in HTML. The supplied TikTok verification file is served at its exact root path. TikTok OAuth callback and webhook URLs are implemented with single-use browser-bound state, encrypted server-side tokens, signature validation and delivery deduplication.
- Public-data caches, bounded refreshes and throttled last-used writes reduce repeated Firestore operations. Function bundles exclude tests and caches; storage retention remains bounded.
- Kalshi coin traders and watchdogs are disabled. Live execution remains gated off.

## Limits and follow-up work

Provider availability, model context and licensing still determine which forecasts can run. Cache changes do not establish a measured billing reduction until production usage is observed.

TikTok's verification file does not constitute approval of Login Kit, Content Posting or webhook flows. A sandbox demo and product-specific review remain separate steps. RapidAPI enterprise pricing and listing publication require final platform configuration. The requested standalone packages, expanded Jev question cards and chart-note interface are not included in this release.
