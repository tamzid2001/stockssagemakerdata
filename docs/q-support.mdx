Open **Support** in the website corner. Ask about forecasts, downloads, workspaces or API access. The assistant selects from curated Quantura help topics and returns the authored answer with a documentation link. Account-specific or uncertain questions route to Contact.

## Recent conversations

Choose **History** to reopen a conversation, **New conversation** to start another, or **Delete** to remove an individual conversation. Up to 20 conversations, with up to 40 messages each, are retained for 30 days on this browser/device and scoped to the current signed-in or guest identity. History is not synchronized between devices. If browser storage is unavailable, help remains available for the current visit.

AI can sometimes make mistakes. Please check important info. Do not send passwords, API keys or private datasets. Support does not place trades, change permissions or inspect private account records.

## API

`POST /api/support/chat` accepts a bounded alternating `messages` array ending in a user question. It uses an authenticated session, including a secure guest session, or an API key with `account:read`. Per-user and global quotas protect the service.

```json
{"messages":[{"role":"user","content":"How do I download my workspace CSV?"}]}
```

Success contains `data.answer`, `data.references`, `data.escalate`, `data.model`, `data.response_mode` (`documented_help`) and `data.knowledge_version`. Errors include 401, 422, 429 and 503. Numerical forecasts are produced by the time-series models separately from Support.

## Operator configuration

`TYPESAFE_API_KEY` belongs only in the server's encrypted runtime/secret store. Typed topic choices and returned probabilities are validated, redirects are forbidden, and provider failures return a safe error without logging the question, credential or provider error body.
