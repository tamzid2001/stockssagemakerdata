Screener help

This page now dispatches the repository GitHub Action and reads the uploaded artifact back into Quantura. The only user input is the market-cap floor, and completed runs remain shareable from My Requests and Explore.

Engine: GitHub Actions workflow running the daily Prophet tracker.
Universe: Combined S&P 500 + Nasdaq scan.
Filter: Market-cap floor only, defaulted to $100B.
Publishing: Completed runs auto-publish to Explore and remain shareable.
How the workflow result is used

Quantura reads the artifact, normalizes active Prophet breach signals, saves the run as a request, and keeps it in sync when you reload it later.
