# Quantura Code of Conduct

## Our standard

Quantura aims to be a respectful, technically serious, and constructive project.

Participants in issues, pull requests, reviews, discussions, and related community spaces are expected to:

- act professionally and in good faith
- focus on evidence, reproducibility, and clear technical reasoning
- welcome different levels of experience
- respect personal boundaries, privacy, and security concerns
- give actionable feedback instead of insults or dismissal

## Unacceptable behavior

The following behavior is not acceptable:

- harassment, hate speech, discriminatory language, or personal attacks
- doxxing, threats, intimidation, or unwanted sexual attention
- trolling, dogpiling, bad-faith debate, or deliberate derailment
- publishing private credentials, personal data, or undisclosed security details
- spam, impersonation, or repeated off-topic promotion

## Scope

This Code of Conduct applies to:

- GitHub issues, pull requests, reviews, and discussions
- project documentation and community support threads
- public spaces where someone is representing the Quantura project

## Maintainer responsibilities

Maintainers may edit, remove, or reject comments, issues, pull requests, or other contributions that violate this Code of Conduct. They may also temporarily or permanently restrict participation when needed to protect the project and its community.

## Reporting

To report a Code of Conduct issue, email `tamzid257@gmail.com`.

Please include:

- a link or screenshot when possible
- a short description of what happened
- any context needed to understand urgency or safety impact

## Enforcement

Maintainers will review reports, determine the appropriate response, and protect reporter privacy as much as practical.

Possible responses include:

- a private warning
- content removal
- temporary participation limits
- permanent ban from project spaces
